🛡️ Why Standard WebAR Fails on Business Cards

Most business cards have large flat cream/white areas with very few corners or edges. MindAR relies on Difference-of-Gaussian (DoG) keypoints in TensorFlow.js shaders. On flat surfaces, these keypoints drop below detection thresholds. To overcome this, we built a 5-layer fallback pipeline:

Layer 1 · camera-preprocess.ts
WebGL Camera Preprocessor (GLSL Fragment Shader)

Intercepts the webcam stream before MindAR sees it. Pass 1 reduces specular glare from glossy card lamination. Pass 2 applies an S-curve contrast boost to midtones. Pass 3 (CLAHE-lite) uses a 4-tap local kernel to stretch luminance ranges on flat card areas, revealing micro-textures.

Layer 2 · react-three-mind
Multi-Target Difference-of-Gaussian / FREAK Detector

MindAR scans video frames across an image pyramid via TF.js WebGL kernels, matching high-frequency corners against the compiled card.mind binary target database.

Layer 3 · mind-ar core
Normalized Cross Correlation (NCC) Tracking

Once detected, locked feature patches are tracked frame-to-frame. Smoothness and jitter resistance are tuned via a 1€ (One-Euro) filter profile (minCF: 0.001, beta: 20).

Layer 4 · phase-correlate.ts
2D FFT Phase Correlation Fallback (fft.js)

When NCC confidence drops during fast card movements or brief finger occlusions, this layer extracts a 64×64 patch around the last-known UV, runs a Hann-windowed 2D FFT cross-power spectrum, and derives sub-pixel translation (dx, dy) to keep the 3D scene locked.

Layer 5 · State Machine
Seamless Re-Detection & Recovery

If Phase Correlation confidence drops below 0.1 for more than 15 consecutive frames, the anchor gracefully disengages and returns to Layer 2 detection without app stutter.

🧊 Glassmorphic Panel Engine (Panel.tsx)

Panels render in real 3D space using @react-three/drei's <Html transform>.
They feature dynamic glassmorphism with backdrop-filter: blur(14px), dark translucent gradients, and subtle rounded border highlights.

4 Spatial Slots:
• overlay: Glued flat to card surface (scanline + animated border)
• top: Tilted backward 35° above card (vCard / Bio)
• left: Angled 23° toward user on left (Social links / GitHub)
• right: Angled -23° toward user on right (Gallery / Video / 3D)

  • FPS Monitor: Warns if frame rates drop below 30fps.
