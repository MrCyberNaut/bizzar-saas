3. HOW THE AR ENGINE ACTUALLY WORKS (THE SECRET SAUCE)
--------------------------------------------------------------------------------
Standard AR engines fail on business cards because cards have large flat areas
with low contrast. Our custom engine solves this using a 5-layer pipeline:

   +--------------------------------------------------------------+
   | Layer 1: WebGL Camera Preprocessing (camera-preprocess.ts)   |
   | Intercepts video feed before MindAR sees it.                  |
   | - Suppresses specular glare from glossy card lamination      |
   | - Boosts midtone edge contrast                               |
   | - CLAHE-lite: 4-tap local histogram stretch on flat regions  |
   +------------------------------+-------------------------------+
                                  |
                                  v
   +--------------------------------------------------------------+
   | Layer 2: MindAR Difference-of-Gaussian / FREAK Detector      |
   | Searches for scale-space corner extrema in TF.js shaders.     |
   | Locks onto the compiled 3-card target binary (card.mind).    |
   +------------------------------+-------------------------------+
                                  |
                                  v
   +--------------------------------------------------------------+
   | Layer 3: Normalized Cross Correlation (NCC) Tracking         |
   | MindAR tracks locked patches frame-to-frame with One-Euro    |
   | filter smoothing (minCF: 0.001, beta: 20).                   |
   +------------------------------+-------------------------------+
                                  |
                                  v
   +--------------------------------------------------------------+
   | Layer 4: FFT Phase Correlation Fallback (phase-correlate.ts) |
   | When MindAR loses tracking (brief occlusion or fast pan),     |
   | runs 64x64 2D FFT cross-power translation recovery.          |
   | Holds the 3D panels in place without dropping the AR scene!  |
   +--------------------------------------------------------------+
